# Methodology comparison prototype

Serve the repository root with `python3 -m http.server 8780 --bind 127.0.0.1`, then open `http://127.0.0.1:8780/prototype/`.

Compare the Swiss-derived illustrative floor, Kazakh annual-shift component and published Koksu snow-trout baseflow. Switch normal/dry forcing and ecology-first/upstream-irrigation-first operation. System shows the same topology and separate R2a/R2b delivery checks before/after drainage returns; each object has a compact assessment-basis record. Review remains five years, with annual record maintenance and earlier reassessment when evidence changes, as explicitly selected by the project lead.

The browser reads four precomputed native result files. Taqsim performed routing, storage, diversion and return calculations; Fishy assessed the two sections against supplied hypothetical criteria. Buttons do not rerun either package. Native sources, inputs and application witnesses are in `../native/koksu/`; review evidence and exact runtime hashes are in `../verification/prototype_2026-10-12/`.

These are illustrative components, not complete interchangeable assessment methods. Swiss coefficients and Q347 are assumptions; Kazakh annual quantile magnitudes and dry scaling are assumptions; the snow-trout schedule is imported from Hayes et al. (2025), DOI 10.1007/s13762-025-06761-2. No local WUA is calculated. Inflow is approximate digitization of the published Koksu monthly medians, held constant within months; dry inflow is 50%. Calendar labels are alignment codes, not observed years. The unmanaged reference is hypothetical, not an accepted natural reconstruction. Colours show modelled quantity delivery, not ecological status or legal fault. The Swiss floor is used as a hypothetical operating target; the report's separate floor-prohibition check is not executed.

This prototype is currently English. The repository's earlier multilingual learning pages remain separate products with separate datasets; their assumptions must not be transferred to this prototype.

Verification: `node --test tests/prototype-*.cjs` from the repository root. Sixteen annual native cases and independent review preceded publication; detailed original physical chunks remain in the local project audit. Archived review files preserve original local evidence references and some findings superseded by the scope update; the current implementation and `SCOPE_UPDATE_REVIEW.txt` record those explanations. No claim of current upstream-main versions or large-basin continuous-run performance is made.
